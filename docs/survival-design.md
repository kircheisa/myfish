## 0. 设计支柱与主题（100原则 · Phase 1）

**三根支柱（动作动词）**：
1. **采集**——潜、摘、抓、伐
2. **建造**——合成、放置、升级营地
3. **生存**——进食、饮水、过夜

**一句话定位**：这是一个"向海洋索取、在海岛扎根"的求生游戏。

**80/20**：玩家 80% 时间 = 游泳捕捞 + 岛上采集建造 → 资源全投这两条主线。

**主题协同（Synergy）**：主题句 **"大海给养，荒岛安家"**。两大系统必须双向打通而非并列：
- 捕捞 → 生鱼 → **烤鱼 = 全游戏最佳食物**（捕捞获得新消耗端）
- 篝火/庇护所 → 恢复状态 → 支撑更远的深潜探索（建造服务探索）
- 口渴耗尽 → 氧气上限暂时减半（陆地状态反哺海洋玩法）
- 主题一致性约束：**治愈系明亮画风，不引入恐怖/黑暗元素**（夜晚危险仅做氛围，不惩罚）

## Phase 1 —— 登岛 & 岛屿扩建

### 1.1 步行模式（双态状态机）

| 项 | 设计 |
|---|---|
| 陆地判定 | `terrainHeight > -0.45`（与游泳阻挡 -0.5 衔接）；-0.45~-1.1 为**涉水带** |
| 状态机 | `swim ↔ wade ↔ walk` 三态；切换播放 0.3s 爬岸过渡（身体前倾） |
| 步行物理 | 速度 4.2 m/s（游泳的 ~60%，泥沙阻力感）；y = 地形高 + 1.05 贴地；坡度 > 0.75 不可攀爬 → 自动绕行；转向 2.4 rad/s |
| 涉水物理 | 速度 2.8 m/s，半身泡水，留涟漪粒子 |
| 动画 | 腿摆频随速度；手臂对摆；停定时呼吸起伏；陆上不耗氧气 |
| 可供性 | 岸边泡沫带已是"可登岸"暗示；登岛瞬间弹字"🏝️ 登上荒岛" |
| 相机 | 陆地机位略抬高（+6/-16 混合），丛林茂密处自动拉近 |

### 1.2 岛屿扩建（面积 ×2.3）

- 主岛 r 78→118、峰高 6.4→9；副岛 r 50→70
- **五区布局**（海滩:丛林:高地比例贴近黄金分割）：
  1. **海滩带**（h 0~1.2）：亮沙、漂流木、螃蟹洞群
  2. **丛林带**（h 1.2~4）：棕榈密度 ×3 + 蕨类（扇形锥）+ 香蕉丛 + 花丛
  3. **溪流**：从高地向海滩 carve 一条 -0.3m 浅带，源头瀑布粒子，两侧圆石，可饮水
  4. **洞穴凹地**（丛林深处）：岩壁环抱，内置宝箱（Phase1 放"探险家遗物"彩蛋）
  5. **瞭望高地**（岛顶）：熄灭的篝火遗址 + 歪脖树，登顶弹全图方位提示
- **环境叙事（世界即角色）**：高脚木屋旁加破损独木舟、熄灭篝火圈、挂着的风化渔网 → 暗示"曾有人在此求生后离开"；洞穴内 3 块探险日志石碑（走近弹短句）→ 故事线指向海沟沉船
- **技术卡点与对策**：
  - 岛高 9 超出高度纹理编码上界（-64~+8）→ H_RANGE 调至 80
  - 溪流用反向 field（负深度浅带）并入 terrainHeight；珊瑚/棕榈/散布密度按新半径参数化
  - 出生点安全：岛心(110,85) 至 (0,-70) 距离 190 > 118+15 ✓ 不重叠
  - 新装饰全走静态合并管线

### 1.3 生存属性（Wither 机制 + 低惩罚原则）

| 属性 | 消耗 | 耗尽效果（不死亡） |
|---|---|---|
| 饥饿 🍗 | -0.5/s（200s 耗尽） | 移速 -40% + 画面微暗 + 弹字"饥肠辘辘" |
| 口渴 💧 | -0.8/s（125s 耗尽） | **氧气上限暂时减半**（与海洋玩法联动） |

- 恢复源：椰子（+30 饥 /+40 渴）、螃蟹（+35 饥）、溪水（口渴直接回满）
- 校准方法（加倍减半）：上线前对 drain 做 2x / 0.5x 对照 → 目标"每 3~4 分钟一次进食需求，不打断核心循环"
- HUD：O2 条下方两条渐变条（🍗/💧），<25% 红色脉冲（复用低氧样式）

### 1.4 新采集物（可供性优先）

- **椰子 🥥**：椰树下可交互物（8 棵树 × 每棵 1，重生 60s）；走近按 E 采集 → **自动库存（上限 5）+ 单键使用**（F 吃椰子）—— Hick 定律：不做物品栏，属性低时主动提示"按 F"
- **螃蟹 🦀**：沙滩 8 字横行 AI，玩家 4m 内斜向逃逸（3.5 m/s < 跑速 4.2 → 追得上）；1.5m 内按空格抓（prob 0.9）→ 蟹肉（F 食用）。运动本身即视觉引导（注意力捕获：运动优先级最高）
- **溪水**：站入溪中按 E → 1s 蹲饮动画 → 口渴回满

### Phase 1 验收清单
- [ ] 任意方向游到岛边可自然登岸，无卡顿穿模；坡地自动绕行

## Phase 2 —— 篝火与制作

### 2.1 资源（Hick：3 类起步）
- 🪵 木头（枯木堆 E 采集）／🌿 藤蔓（丛林植物）／🪨 石头（岩块敲击）＋棕榈叶（树下拾取）
- 各上限 20（防囤积破坏节奏）；HUD 资源小条（饥饿条下方，非零才显示）

### 2.2 制作（3 配方，V 键轮盘，Hick 最优区间）

| 配方 | 成本 | 效果 | 协同点 |
|---|---|---|---|
| **篝火** | 木3+石2 | 暖光 PointLight+火焰粒子；靠近按 E 烤鱼（生鱼→饥饿+70）；篝火旁饥饿消耗 -50%（温暖 buff） | 每捕一条鱼自动 +1 生鱼库存 → **捕捞喂养生火** |
| **庇护所** | 木5+叶4+藤2 | 手动存档点 + 按 E 休整（饥饿口渴各回 30%） | Phase3 解锁过夜 |
| **水袋** | 藤2+椰壳1 | 携 2 次饮水，溪边装满，F 饮用 | 深潜前的**三角决策**：带补给深潜 vs 轻装快返 |

- 放置模式：Ghost 预览（绿/红有效性），坡度与水域校验

### 2.3 奖励组合（固定建立信任 + 可变刺激探索）
- 固定：配方效果恒定
- 可变：洞穴宝箱每 10 分钟刷新，随机掉落（珍珠×2 / 传说鱼饵·下次捕获必中 / 资源包）

## Phase 3 —— 狩猎与昼夜

### 3.1 野猪（技能型挑战 + 动态难度 Buster）
- 3 头丛林 waypoint 巡逻；8m 警觉（抬头）、5m 冲撞（3.5 m/s，被撞：饥饿 -10 + 击退）
- **长矛**（木2+石1，Phase2 配方追加）：2.2m 近战，4 次击倒 → 野猪肉 ×2（烤后 +120 饥饿，全游戏最佳食物）→ 高风险高回报
- 动态难度：被同一头猪连撞 3 次 → 其警觉半径暗中 -20%（玩家无感知，保住成就感）
- 环境叙事：拱翻的泥地、咬破的香蕉丛 = 领地暗示，玩家先"读环境"再遇敌

### 3.2 昼夜循环（节奏：8 分钟 = 昼5.5/黄昏0.8/夜1.7）
- 太阳角度+色温插值沉落；丛林变暗；萤火虫粒子；**篝火价值在夜晚凸显**
- 危险轻量化：夜间丛林边缘"发光眼睛"氛围生物（不攻击，靠近惊散）——治愈系红线
- 庇护所过夜：E → 黑屏 2s → 天亮，饥饿口渴 -15%（跳夜的代价）
- **锚定效应**：首个夜幕前 30s 弹提示"夜幕将至，回到篝火旁"——首次体验必须精心设计

### 3.3 求生成就线（6 项）
荒岛足迹（首次登岛）／篝火晚宴（烤第一条鱼）／建筑师（庇护所）／猎人（猎野猪）／溪边安家（饮水 ×10）／求生大师（存活游戏内 3 天）
